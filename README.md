# ELVISB Report

Aplicación Android independiente para reportes fotográficos.

- Cámara interna.
- Timestamp permanente sobre la imagen.
- Importación desde galería.
- Comentarios por fotografía.
- Reportes múltiples guardados localmente.
- Exportación a PDF mediante el sistema de impresión de Android.
- Sin cuenta, suscripción ni límites artificiales.

El APK de depuración se genera automáticamente con GitHub Actions como **ELVISB-REPORT.apk**.
